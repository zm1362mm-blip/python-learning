۱. شروع کار با پایتون

۲. متغیرها و انواع داده

ذخیره متن، عدد و مقدارهای درست/نادرست.

مشاهده درس

متغیر نامی برای نگهداری داده است. برای متن از رشته و برای عدد از int یا float استفاده می‌شود.

۳. ورودی و خروجی

دریافت اطلاعات از کاربر و نمایش نتیجه.

مشاهده درس

تابع input داده را به‌صورت متن می‌گیرد؛ برای عدد می‌توان از int(input()) استفاده کرد.

۴. شرط‌ها

در پایتون تورفتگی ابتدای خط‌ها مهم است.

۵. حلقه‌های for و while

۹. توابع

پارامترها ورودی تابع‌اند و return نتیجه را برمی‌گرداند.

مشاهده درس

۱۴. JSON و آشنایی با API

۱۵. پایگاه داده SQLite

مشاهده درس
import sqlite3 connection = sqlite3.connect("app.db") connection.execute("CREATE TABLE IF NOT EXISTS notes (text TEXT)") connection.execute("INSERT INTO notes VALUES (?)", ("سلام",)) connection.commit() connection.close()

۱۶. ساخت سایت با Flask

مقدمه‌ای برای ساخت وب‌سایت با پایتون.

مشاهده درس
from flask import Flask app = Flask(__name__) @app.route("/") def home(): return "سلام از سایت پایتونی!" # برای اجرا باید Flask نصب باشد و سرور اجرا شود.

این کد به نصب Flask و اجرای سرور نیاز دارد؛ در محیط مرورگر این صفحه مستقیماً اجرا نمی‌شود.

۱۸. رسم شکل با Turtle

شروعی ساده برای گرافیک و رسم الگوها.

مشاهده درس
import turtle pen = turtle.Turtle() for _ in range(4): pen.forward(100) pen.right(90) turtle.done()

این کد در محیط‌هایی که پنجره گرافیکی Turtle دارند اجرا می‌شود.

تنظیم پیشرفت

پیشرفت درس‌ها در این نسخه روی همین دستگاه ذخیره می‌شود.

ذخیره‌سازی این نسخه با حافظه مرورگر (localStorage) انجام می‌شود؛ با پاک‌کردن داده‌های مرورگر یا استفاده از دستگاه دیگر، اطلاعات ممکن است از بین برود. برای حساب‌های واقعی و همگام‌سازی بین کاربران، سرور و پایگاه داده لازم است.

📖 واژه‌نامه برنامه‌نویسی

Variable — متغیر

نامی برای نگهداری یک مقدار در برنامه.

Function — تابع

بخش قابل استفاده مجدد از کد که می‌تواند ورودی و خروجی داشته باشد.

Loop — حلقه

ساختاری برای تکرار یک یا چند دستور.

List — لیست

مجموعه‌ای مرتب و قابل تغییر از عناصر.

Debug — اشکال‌زدایی

پیدا کردن و اصلاح خطاهای برنامه.

API — رابط برنامه‌نویسی

روشی تعریف‌شده برای ارتباط بین نرم‌افزارها.

Library — کتابخانه

مجموعه‌ای از کدهای آماده برای استفاده در برنامه.

Class — کلاس

الگویی برای ساخت اشیا در برنامه‌نویسی شیءگرا.
